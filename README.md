## About

identifier/identifier is a specification of common interfaces for representing and creating identifiers in PHP. For more information, [read the specification](https://php-identifier.readthedocs.io).

This project adheres to a [code of conduct](CODE_OF_CONDUCT.md). By participating in this project and its community, you are expected to uphold this code.

## Installation

Install this package as a dependency using [Composer](https://getcomposer.org).

```bash
composer require identifier/identifier
```
